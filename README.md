# Neologism Homebrew Tap

This is Neologism's Homebrew tap for distributing custom developer workflow tools.

## Available Tools

### git-reset-changes

An interactive TUI utility to safely reset file changes back to their state on a source branch.

```bash
# 1. Tap the repository
brew tap neologism-research/tap

# 2. Install the tool (Homebrew will handle installing fzf automatically)
brew install git-reset-changes
```
